Campus Customs – Application check (Problem 11)

Live site tested in Google Chrome on the final Problem 10 storefront. Every number below was checked against data/campus_customs.db. Overall: PASS (23/23 checks)

How the tests were run

The real application ran locally (FastAPI backend with the PydanticAI agent on gpt-5.6-luna via Portkey, and the Vite React storefront). A script drove a real Google Chrome browser through it, clicking, typing and waiting for chatbot replies, and saved the screenshots below. Every value the chatbot displayed was compared with a direct, read-only query of data/campus_customs.db.

The three required checks: (1) inventory lookup in chat, (2) dynamic search-result cards after a category question, and (3) a Problem 9 usability feature (the no-results state with Clear search).

Check 1 – Chat inventory lookup (stock and price from the database)

What was testedThe chatbot answers a size and stock question with the real quantity and price, using the Problem 6 inventory and price tools.

ExpectedThe exact stock for size M and the price, from the database. Database: Yale Dad Hoodie price $68.00; size M quantity 12 (all sizes: XS = 5, S = 5, M = 12, L = 20, XL = 12, XXL = 15).
Actual
The Yale Dad Hoodie is $68.00. We have 12 in size M.
PASS The reply's quantity (12) and price ($68.00) match the database exactly. The Yale Dad Hoodie product card is shown under the answer.

This screenshot proves the live chatbot looked up real inventory: it reports 12 in size M at $68.00, exactly the values stored in inventory and catalogue.
